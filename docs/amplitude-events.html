Amplitude 이벤트 정의서

모든 이벤트에 환경, 앱 표면, 앱 버전, 계정 유형을 붙입니다. 사용자 작성 내용과 직접 식별 정보는 보내지 않습니다.

핵심 회고 이벤트

이벤트발생 시점주요 속성
retrospect_start_clicked시작 버튼 클릭source
retrospect_startedV2 생성 성공retrospective_id, source, 유입 정보
retrospect_answer_submitted답변 저장 성공turn_id, turn_number, input_type
retrospect_exited나가기 확정last_completed_turn
retrospect_completedDB 완료와 결과 조회 성공answer_count, turn_count, elapsed_duration_sec, active_duration_sec, 유입 정보
retrospect_complete_failed완료 실패reason(timeout·network·server·generic), last_completed_turn

유입

campaign_opened은 이메일 링크 또는 푸시 탭에서 발생하며 7일 동안 회고 시작·완료에 연결됩니다.

조회 기준

기본 필터는 environment=production, account_type=CUSTOMER입니다. 공식 KPI는 DB 기반 어드민 지표를 사용합니다.
